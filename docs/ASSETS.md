# Storefront assets

`public/images/` contains six generated still-life concept images created specifically for this storefront design direction. Five represent category ingredients as editorial illustrations; `hero-preview.png` is an intentionally unbranded tin-and-cup concept. None depicts verified Nilkurinji packaging or certifies the real contents of any product.

| File | Intended use | Review gate |
| --- | --- | --- |
| `hero-preview.png` | Local homepage preview only | Replace with owner-approved real brand/product photography before production hero approval |
| `category-tea.png` | Tea category editorial tile / fallback illustration | Owner approves as category illustration or replaces it |
| `category-tea-bags.png` | Tea Bags category editorial tile / fallback illustration | Owner approves as category illustration or replaces it |
| `category-rice.png` | Rice category editorial tile / fallback illustration | Owner approves as category illustration or replaces it |
| `category-snacks.png` | Snacks category editorial tile / fallback illustration | Owner approves as category illustration or replaces it |
| `category-other-foods.png` | Other Foods category editorial tile / fallback illustration | Owner approves as category illustration or replaces it |

Live product-card imagery and galleries come from Shopify product media. The live home hero uses the image reference from the Shopify `nilkurinji_home` metaobject; until one is supplied, a neutral placeholder appears. Review or replace the category illustrations before launch so they cannot be mistaken for actual product photos. Keep generated pack designs preview-only unless the owner approves the exact packaging against production inventory.

All image files are local so the preview works without external image calls. Shopify-hosted images are allowed from `cdn.shopify.com` by Next Image configuration.
